# 🎓 Online Test Platformasi

Professional va ishlab chiqarishga tayyor web-based test platformasi.

## ✨ Xususiyatlar

### 🎯 Asosiy funksiyalar
- **500+ savollar bazasi** - Keng qamrovli test banki
- **200 ta tasodifiy savol** - Har safar yangi test
- **Avtomatik javob aralashtirish** - To'g'ri javob A, B, C yoki D bo'lishi mumkin
- **Timer** - Test vaqtini kuzatish
- **Progress tracking** - Real vaqt rejimida jarayon kuzatuvi
- **Question navigation** - Istalgan savolga o'tish imkoniyati

### 🎨 Dizayn va UX
- **Dark/Light mode** - Tungi va kunduzgi rejimlar
- **Responsive design** - Mobile, tablet va desktop moslashgan
- **Glassmorphism effects** - Zamonaviy shisha effektlari
- **Smooth animations** - Yumshoq o'tish animatsiyalari
- **Professional UI** - Milliy test platformalari darajasida

### 📊 Natijalar va Tahlil
- **Batafsil statistika** - Ball, foiz, to'g'ri/noto'g'ri javoblar
- **Chart.js grafiklari** - Vizual ma'lumotlar ko'rinishi
- **Performance analysis** - Baholash va tavsiyalar
- **Download natija** - TXT formatda yuklab olish

### 🎉 Celebration Effects
- **Confetti animation** - 40+ to'g'ri javob uchun nishonlash
- **Motivatsion xabarlar** - Foydalanuvchini rag'batlantirish
- **Premium animatsiyalar** - Yuqori sifatli effektlar

### 🏆 Leaderboard tizimi
- **localStorage** asosida reyting
- **Top 100** eng yaxshi natijalar
- **Medal tizimi** - 🥇🥈🥉 birinchi 3 ta o'rin uchun
- **Sana va vaqt** - Har bir natija uchun
- **Backend integratsiyaga tayyor** - Firebase/Database uchun arxitektura

## 🚀 Qanday ishlatish

### Oddiy ishga tushirish
1. `index.html` faylini brauzerda oching
2. Ismingizni kiriting
3. "Testni boshlash" tugmasini bosing
4. Savollarga javob bering
5. Natijangizni ko'ring!

### Savollarni qo'shish
`index.html` faylidagi `QUESTION_BANK` arrayiga o'z savollaringizni qo'shing:

```javascript
const QUESTION_BANK = [
    {
        id: 1, 
        subject: "Fan nomi", 
        question: "Savol matni?", 
        correctAnswer: "To'g'ri javob"
    },
    // ... 500 ta savol
];
```
